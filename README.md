# だれかな？ばあ！

くさむらを触ると動物が「ばあ！」と出てくる、2歳向けの遊び画面。電車などでぐずったときにスマホを渡す用。

- 触る場所：くさむら（動物が出る）／出ている動物（動く）／すけまる（鈴の音で「ばあ」）／それ以外（シャボン玉）
- 失敗・文字・広告・外へのリンクなし。電波なしで動く
- おしまいタイマー（5〜20分）：1分前から夕方 → みんなで「またね」→ 夜になって すけまるが寝る（画面の常時点灯も切る）
- 大人のメニュー：右上のすみを3秒長押し
- 画面の固定はスマホ側の機能を使う（iPhone＝アクセスガイド、Android＝アプリ固定）。手順はアプリ内にある

## 絵

`動画/すけまるチャンネル/design/gemini/cut/` の切り絵を縮めたもの。作り直しは `tools/make_img.py`（切り詰め → 高さ440pxのwebp、アイコンも作る）。Pythonは `動画/すけまるチャンネル/.venv` を使う。

## 更新するとき

`sw.js` の `CACHE_NAME` の版数を上げる（上げないとスマホ側に反映されない）。
